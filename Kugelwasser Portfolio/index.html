Über mich

Hallo! Ich bin Kugelwasser, bürgerlich Luca. Ich interessiere mich sehr für Technologie und ihrem Umfeld. Meine Begeisterung für die digitale Welt erschien mir erstmals 2021, als ich mit einfachen Programmiersprachen anfing und mich immer ein bisschen mehr für Technik und Computer interessierte.

Sprachen & Technologien

Sprachen und Technologien, mit denen ich arbeite

HTML

Die Standard-Markup-Sprache zum Erstellen von Webseiten und Webanwendungen, die Struktur für Webinhalte bereitstellt.

CSS

Eine Stylesheet-Sprache zur Beschreibung der Formatierung von HTML-Dokumenten, einschließlich Layout, Farben und Schriftarten.

JavaScript

Eine Programmiersprache, die interaktive Webseiten ermöglicht und neben HTML und CSS ein wesentlicher Bestandteil von Webanwendungen ist.

Kotlin

Eine moderne Programmiersprache für die JVM, die Entwicklung von Android-Apps und anderen Anwendungen mit besserer Syntax und Sicherheit ermöglicht.

Jetpack Compose

Ein modernes UI-Toolkit für Android-Entwicklung mit Kotlin, das die Erstellung von Benutzeroberflächen deklarativ und intuitiv macht.

XML

Eine Auszeichnungssprache zur Darstellung hierarchischer Daten in einem strukturierten Format, die in vielen Anwendungen wie Konfigurationsdateien und Datenübertragung verwendet wird.

Lua

Eine Skriptsprache, die für die Erstellung von Anwendungen und Spieleprogrammierung verwendet wird.
